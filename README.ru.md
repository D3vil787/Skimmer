# Skimmer

**Быстрый портативный просмотрщик фотографий для папок с десятками тысяч снимков.**
Один `.exe`, без установки, без баз данных и лишних функций.

[English version](README.md)

Интерфейс как у классического проводника: слева дерево папок, справа превью. Пока папка открыта,
программа в фоне создаёт превью **для всех** файлов в ней и складывает их в компактный дисковый кэш.
При следующем открытии папки всё появляется мгновенно.

## Возможности

- **Привычный интерфейс** – дерево папок + сетка превью, адресная строка-«крошки» (клик по папке пути – переход, › – список подпапок, клик по пустому месту – ввод пути), назад / вперёд / вверх, можно перетащить папку или фото на окно.
- **Подпапки плитками** с превью первых фото внутри; при переходе *вверх* выделяется папка, из которой вы пришли.
- **Выделение как в проводнике** – Ctrl+клик, Shift+клик, Shift+стрелки, Ctrl+A; `Del` – в корзину, `Shift+Del` – удалить безвозвратно (Windows спросит). Работает и в полноэкранном просмотре – удобно отбраковывать кадры.
- **Живое обновление** – новые, удалённые, переименованные и перезаписанные фото появляются сами (у докачивающегося файла превью появится, когда он допишется); прокрутка и выделение не сбрасываются.
- **Рассчитан на огромные папки** – сетка полностью виртуальная: 50 000 фото в одной папке работают так же легко, как 50.
- **Мгновенные превью из постоянного кэша** – при повторном открытии папки все превью уже готовы.
- **Фоновая индексация** – пока программа запущена, она индексирует папки, которые вы укажете в *Настройках* (с вложенными), и периодически перепроверяет их.
- **Полноэкранный просмотр** – двойной клик или `Enter`. Соседние фото декодируются заранее, а пока грузится оригинал, сразу показывается превью из кэша, поэтому листание стрелками происходит без задержек.
- **Ориентация EXIF**, «человеческая» сортировка (`img2` раньше `img10`), сортировка по имени / дате / размеру.
- **Портативность** – настройки (`Skimmer.settings.json`, `theme-settings.json`, `update-state.json`) и кэш (`SkimmerCache\`) лежат рядом с `Skimmer.exe`. Если папка только для чтения – используется `%LOCALAPPDATA%\Skimmer`.
- **Самоочищающийся кэш** – кэш папок, которые не открывали N дней (по умолчанию 30), удаляется автоматически; есть ещё ограничение общего размера (по умолчанию 4 ГБ).
- **Автообновление из GitHub Releases** – о новой версии сообщает баннер под панелью инструментов (проверка при запуске и раз в сутки); новый exe скачивается, проверяется по SHA-256 и подменяет старый.
- Внешний вид по [бренд-буку UiKit](https://github.com/D3vil787/UiKit): светлая (Fluent Light), тёмная (Graphite Dark) или «Как в Windows», переключение на лету; шесть акцентных цветов; плотность списка; интерфейс на русском и английском.

Форматы: JPEG, PNG, BMP, GIF, TIFF, ICO, JPEG XR, а также WebP и HEIC, если в Windows установлены соответствующие кодеки.

## Клавиши

| Где | Клавиша | Действие |
|---|---|---|
| Сетка | стрелки, `PgUp`/`PgDn`, `Home`/`End` | перемещение выделения |
| Сетка | `Enter`, двойной клик | открыть фото / открыть папку |
| Сетка | Ctrl+клик, Shift+клик, `Shift`+стрелки, `Ctrl+A` | выделение нескольких |
| Сетка | `Del` / `Shift+Del` | в корзину / удалить безвозвратно (с вопросом, по умолчанию «Нет») |
| Сетка | правый клик, `Menu`, `Shift+F10` | стандартное меню проводника («Открыть с помощью», «Отправить», «Копировать», «Свойства»…) и свои пункты «Просмотр в Skimmer», «Копировать путь» |
| Везде | `F5` | обновить папку |
| Везде | `Alt+←` / `Alt+→` / `Alt+↑` | назад / вперёд / вверх |
| Везде | `Ctrl+L` | адресная строка |
| Просмотр | `→` `↓` `PgDn` `Пробел` / колесо вниз | следующее фото |
| Просмотр | `←` `↑` `PgUp` `Backspace` / колесо вверх | предыдущее фото |
| Просмотр | `Home` / `End` | первое / последнее |
| Просмотр | `Z` или средняя кнопка | масштаб 100 % (перетаскивание мышью) |
| Просмотр | `I` | показать / скрыть строку информации |
| Просмотр | правый клик, `Menu` | меню проводника для открытого фото |
| Просмотр | `Del` / `Shift+Del` | удалить текущее фото и перейти к следующему |
| Просмотр | `Esc`, `Enter`, двойной клик | закрыть |

Можно запускать так: `Skimmer.exe "D:\Photos"` или `Skimmer.exe "D:\Photos\img.jpg"` (удобно для «Открыть с помощью»).

## Скачать

Скачайте `Skimmer.exe` в разделе [**Releases**](../../releases) (или в артефактах *Actions* любого коммита).
Всё необходимое уже внутри (~60 МБ), ничего устанавливать не нужно. Windows 10 / 11, x64.

## Обновления

Через несколько секунд после запуска и затем раз в сутки Skimmer проверяет `github.com/D3vil787/Skimmer/releases/latest`
(можно отключить в *Настройках*, там же кнопка *Проверить сейчас*). Если есть новая версия, под панелью инструментов появляется
баннер цвета акцента (*Что нового*, *Обновить*, *Позже*, ×) и ссылка в статус-баре; *Позже* и × скрывают баннер для этой версии.
Без интернета программа ничего не сообщает.
*Обновить и перезапустить* скачивает новый `Skimmer.exe`, сверяет его с
`SHA256SUMS.txt` из релиза, переименовывает работающий exe в `*.old`, кладёт новый на его место и перезапускается.
Настройки и кэш сохраняются. Если папка программы только для чтения – открывается страница релиза.

## Как устроен кэш

Для каждой папки в `SkimmerCache\` хранятся два файла (имя – хэш пути к папке):

- `*.dat` – превью (JPEG 256 px, качество 80), записанные подряд,
- `*.idx` – небольшой индекс: имя файла, дата изменения, размер, позиция в `.dat`.

При открытии папки индекс читается в память. Превью считается актуальным, пока имя, дата изменения и размер
файла не изменились, поэтому изменённые фото пересоздаются автоматически. Превью удалённых файлов
вычищаются, когда их накапливается много. Папки, которые не открывали заданное число дней, удаляются целиком.

Превью создаются через Windows Imaging Component с масштабированием на этапе декодирования JPEG
(DCT scaling) – это в разы быстрее, чем декодировать картинку целиком.

## Сборка

Нужен .NET 8 SDK под Windows.

```bat
build.bat
```

или

```bat
dotnet publish Skimmer.csproj -c Release -p:PublishSingleFile=true -o out
```

Результат – `out\Skimmer.exe`.

**Релизы** выпускаются автоматически: каждый push в `main` собирается в GitHub Actions, и если для `<Version>` из
`Skimmer.csproj` ещё нет тега `vX.Y.Z`, workflow создаёт этот релиз с `Skimmer.exe` и `SHA256SUMS.txt`.
То есть выпустить версию = поднять номер версии.
